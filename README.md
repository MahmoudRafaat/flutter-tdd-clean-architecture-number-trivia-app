# TDD clean architecture number trivia app

A Flutter app demonstrating Clean Architecture and TDD.

## Features

- Fetch random number trivia
- Search trivia for specific numbers
- Cache last trivia offline

## 📦 Packages Used

| Package                    | Description                              |
|----------------------------|------------------------------------------|
| `bloc`                     | State management using BLoC pattern      |
| `get_it`                   | Dependency injection and service locator |
| `mockito`                  | Mocking library for unit testing          |
| `build_runner`             | Code generation and build tool             |
| `dartz`                   | Functional programming tools for Dart      |
| `http`                     | HTTP client for REST API calls             |
| `shared_preferences`       | Local storage for caching simple data     |
| `data_connection_checker_nulls` | Check internet connectivity status    |
